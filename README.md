`Python` `FastAPI` `LangChain` `Chroma` `Hugging Face` `Groq`

### 🎬 [Video Maker — AI Video Generation Pipeline](https://github.com/Matcry12/Video-Maker)
End-to-end pipeline that converts a text prompt into a YouTube Shorts video with TTS, subtitles, images, and BGM. Optimized rendering **27.5× faster** (407s → 14.8s) and eliminated TTS subtitle drift entirely.
`Python` `Gemini` `Groq` `Edge-TTS` `FFmpeg` `Crawl4AI` `Flask`
